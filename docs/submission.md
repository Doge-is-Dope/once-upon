# Submission draft

## One-line pitch

Two friends answer in private while ChatGPT generates the case, follows the evidence, and tries to catch the secret Mirror.

## What makes it different

Can You Be Me? turns WebMCP into a live game-master protocol rather than a one-shot assistant button. ChatGPT owns every question and investigative decision, but Supabase owns identity, secrecy, timing, idempotency, and the legal state transitions. The Detective can be interrupted and resume from durable evidence without exposing either player's private information.

## Demo outline (2:40–2:52 target)

1. Create a room and scan the QR code from two phones.
2. Show WebMCP discovery and ChatGPT generating the five-question Learn batch.
3. Lock answers privately and reveal both atomically on the Host Board.
4. Reveal Original/Mirror roles on phones, then run an adaptive Challenge.
5. Show the Q3 blind Objection and targeted follow-up.
6. Commit the accusation, reload during the countdown, and reveal the durable result/timeline.
7. Close on the security boundary: the Detective saw only public evidence.
